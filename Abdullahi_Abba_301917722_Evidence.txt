Book 10 has only 1 copy and it is already borrowed (available = 0 )
Before: loans = 13

=== Test 3: concurrency control (two users at the same time) ===
User A started borrowing book 2 (not committed yet). A sees copies = 1
User B reads book 2 meanwhile and sees copies = 2 -> no dirty read (isolation)
User B tries to write book 2 at the same time -> database is locked -> blocked, so no lost update
User A COMMITTED.
User B retries after A finished: B now sees copies = 1
User B COMMITTED. Final copies of book 2 = 0 (2 total - 2 borrowers = 0, correct)
